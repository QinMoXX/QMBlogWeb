# 从零学习 Rust、Bevy 与 bevy_immediate

这是一套面向 Rust、Bevy 初学者的项目实践教程。你不需要先理解泛型约束、自定义 `SystemParam` 或底层查询实现。

我们先完成一个能显示文字、响应点击、增删列表的程序，再逐步拆开本项目的实现。你可以把本目录当作一份按章节阅读的小书。

## 最终会做出什么

1. 一个 Bevy 窗口。
2. 使用普通 Bevy UI 实现的键盘计数器。
3. 使用 bevy_immediate 实现的文字界面和点击计数器。
4. 可以添加、删除、倒序排列条目的列表。
5. 两个状态独立、结构复用的计数器面板。
6. 一个只有标准库的简化“即时界面内核”，再把它接入真正的 Bevy 实体。
7. 一个自己实现的 `.highlighted(...)` 扩展方法。

教程有两种“从零”：前半部分从零搭建应用；第 07、07B 章从零实现核心算法的教学模型和最小 Bevy 插件。教学模型刻意简化，不包含完整布局、事件传播或本项目的所有功能。

## 开始运行

所有命令默认在仓库根目录 `bevy_immediate/` 执行。示例是一个单独的小工程，位于 [tutorial](/game/rust/bevy-immediate/appendix/running)，不需要修改原来的 examples 或 workspace 配置。

```bash
cargo run --manifest-path Doc/tutorial/Cargo.toml --bin lesson01_window
```

完整代码在 [tutorial/src/bin](/game/rust/bevy-immediate/examples/main)，公共的窗口、容器、按钮外观在 [tutorial/src/lib.rs](/game/rust/bevy-immediate/examples/lib)。文中的短代码会注明是“片段”还是“完整程序”。不需要把片段单独当成一个 Rust 文件运行。

窗口内的示例文字使用英文，方便直接使用默认字体；教程说明使用中文。显示中文需要另外加载包含中文字形的字体，本教程没有捆绑字体文件。

## 版本与验证范围

本教程针对当前仓库：Rust edition 2024、根项目声明的最低 Rust 版本 1.97.1、Bevy 0.20.0、bevy_immediate 0.9.0。教学工程通过本地 `path` 依赖使用这份仓库代码，不要求从 crates.io 安装本库。

编译检查、纯 Rust 模型的运行结果，以及窗口交互是否实际验证，见 [验证记录](/game/rust/bevy-immediate/appendix/validation)。不同 Bevy 版本的教程代码可能无法直接混用。
