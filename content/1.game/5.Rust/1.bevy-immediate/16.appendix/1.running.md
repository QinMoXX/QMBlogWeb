## 在哪里执行命令

本博客提供教程章节、完整示例和引用源码的阅读快照。运行示例需要准备教程对应的 `bevy_immediate` 源码仓库（Bevy 0.20.0、bevy_immediate 0.9.0），其中应包含 `Doc/tutorial` 教学工程；博客本身不是 Rust 工程。

章节中的运行命令从该源码仓库根目录执行：

```bash
cd bevy_immediate
cargo run --manifest-path Doc/tutorial/Cargo.toml --bin lesson01_window
```

不要把笔记里的 Cargo.toml 放到博客目录后直接运行：原配置中的 `path = "../.."` 指向原项目根目录，移动目录会改变其含义。要修改示例，请编辑原项目 `.rs` 文件，博客中的代码页面是带语法高亮的完整阅读快照。
