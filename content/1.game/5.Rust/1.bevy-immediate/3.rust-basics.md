## 1. 变量与可变性

```rust
let count = 0;
let mut other = 0;
other += 1;
```

`let` 声明变量。没有 `mut` 时，不能重新赋值；有 `mut` 才允许修改。`+= 1` 就是“在原来的值上加一”。

Rust 会推导许多变量的类型，但可以显式写出来：`let count: u32 = 0;`。`u32` 是 32 位无符号整数，不表示负数。

## 2. 结构体把相关数据放在一起

```rust
struct Counter {
    value: u32,
}

let mut counter = Counter { value: 0 };
counter.value += 1;
```

`Counter` 是一种自己定义的类型。花括号里的 `value` 是字段。`counter.value` 表示读取或修改某个具体计数器的字段。

类型名和变量名不同：`Counter` 是设计图，`counter` 是按这张图创建出来的一份数据。

## 3. 函数、引用与借用

```rust
fn increment(counter: &mut Counter) {
    counter.value += 1;
}

increment(&mut counter);
```

逐个读：

- `fn` 定义函数。
- `counter: &mut Counter`：接收一个“允许修改 Counter 的临时访问权”。
- 调用时的 `&mut counter`：把当前变量暂时借给函数修改。

这里没有复制整个计数器，也没有把它永久交给函数。

| 写法 | 当前阶段的理解 |
|---|---|
| `Counter` | 一份 Counter 数据；按值传递时可能转移所有权 |
| `&Counter` | 借来看，不允许通过它修改 |
| `&mut Counter` | 借来修改 |

最常用的规则：同一时间，可以有多个共享借用，或者一个可变借用。不能在读取一个容器的同时又随意改变它的结构。

这条规则后面会解释为什么“遍历列表时记录要删除的 ID，遍历结束后再删除”。

## 4. `String`、`&str` 和 `format!`

```rust
let fixed: &str = "Hello";
let owned: String = String::from("Hello");
let message = format!("Count: {}", counter.value);
```

`&str` 是借用的字符串片段，`String` 是拥有自己内容的字符串。字符串字面量 `"Hello"` 可以直接写成 `&str`。

`format!` 把数值填入 `{}`，产生一个新的 `String`。名字后面的 `!` 表示它是宏，初学时可以先把它当作一种特殊调用写法。

界面里的 `.text("Hello")` 和 `.text(format!(...))` 都会用到这些类型。

## 5. 闭包就是可以当参数传递的小函数

```rust
let add_two = |value: u32| value + 2;
let result = add_two(1);
```

`|value: u32|` 是参数列表，后面是函数体。最后没有分号的表达式可以作为返回值，所以结果是 3。

```rust
ui.add(|ui| {
    // 在这个小函数里描述子节点
});
```

这是后续会出现的片段：我们把“如何创建子节点”的逻辑交给 `.add()`。闭包也能使用外面的变量，这叫捕获。它借用还是取得所有权，取决于具体写法和使用方式。

`|| panel()` 没有参数；`|ui| ...` 有一个参数。函数本身也能作为参数：`.on_spawn_insert(panel)` 相当于“需要时调用 panel 函数”，不是马上执行它。

## 6. `impl`、方法和 trait

```rust
trait Describe {
    fn description(&self) -> String;
}

impl Describe for Counter {
    fn description(&self) -> String {
        format!("Count: {}", self.value)
    }
}
```

`trait` 定义一份约定；`impl Describe for Counter` 表示 Counter 遵守这份约定，并提供具体方法。

`&self` 是“借用调用这个方法的对象”。因此可以写 `counter.description()`。

后面你会看到 `impl ImmediateAttach<CapsUi> for CounterRoot`。先读成：“为 CounterRoot 提供库所要求的界面构建方法。”

扩展方法有时需要先 `use` 对应 trait 才能调用。`.text()` 报“找不到方法”时，原因可能是忘了导入 `ImmUiText`。

## 7. 泛型先读成占位符

`Vec<Item>` 是装 Item 的可增长列表。`Option<u64>` 是“有一个 u64，或者没有值”。`Imm<CapsUi>` 是使用 CapsUi 能力集合的界面上下文。

尖括号不是小于号，它在这里提供类型参数。

`Option` 常见的处理方式：

```rust
let selected: Option<u64> = Some(3);
if let Some(id) = selected {
    println!("Selected: {id}");
}
```

`Some(3)` 表示有值，`None` 表示没有值。`if let` 在匹配成功时取出里面的值。

## 8. 元组、默认值与派生

```rust
(Text::new("Hello"), CounterLabel)
```

圆括号可以把多份数据组成元组。Bevy 允许用元组一次提供多个组件。

```rust
Node {
    width: Val::Px(200.0),
    ..default()
}
```

这是后续 UI 片段：只指定宽度，其他字段使用默认值。`..default()` 不是循环，也不会自动复制当前节点的数据。

`#[derive(Default)]` 让 Rust 为类型生成默认值实现。像只有整数的 Counter，默认字段值就是零。Bevy 的 `#[derive(Component)]`、`#[derive(Resource)]` 则用来使类型符合相应的框架约定。

## 小练习

把基础程序中的 `add_two` 改成加五，输出应变成 `Count: 6`。再把 `increment` 改成接收 `&Counter`，观察编译器为什么不允许它修改 `value`。看完报错后恢复 `&mut Counter`。

能解释这个报错，就已经为理解 Bevy 的 `Res` 和 `ResMut` 做好了准备。
