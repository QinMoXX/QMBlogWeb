检查全工程时使用根目录的 target 缓存：

```bash
CARGO_TARGET_DIR=target cargo check --offline --locked --manifest-path Doc/tutorial/Cargo.toml --bins
cargo fmt --manifest-path Doc/tutorial/Cargo.toml --check
```

`--offline` 表示这次验证使用已有依赖缓存；新环境首次运行可能仍需联网下载。`Cargo.lock` 已保留，以记录本次教学工程的依赖解析结果。

## 验证边界

本次没有启动并逐个实际操作图形窗口，也没有对窗口截图做视觉核对。窗口内容与交互是各章给出的预期验收步骤；编译检查不等于已经验证图形驱动、布局外观、指针事件或键盘操作。

`cargo check` 检查类型和 API 使用，不会生成所有最终可执行程序来验证链接与运行。标准库模型的两个测试验证的是教学算法，不是 Bevy 真实内核、完整事件调度或本库全部功能。

没有修改原项目运行逻辑或 workspace 成员，所有新增内容位于 `Doc/`。
